## 🇬🇧 English Documentation

Welcome to the **Frontend (Mobile App)** component of **My Party**. Built meticulously using **Flutter**, this application delivers an ultra-smooth, cross-platform experience for Android and iOS users. It connects to our central Node.js backend using REST APIs and Socket.io for a real-time event management experience.

### ✨ Key Features
- **Modern UI/UX**: Sleek interfaces built entirely with Flutter standard widgets and custom design systems.
- **Real-Time Data**: Instant synchronization of events and notifications using Socket.io.
- **Provider & State Management**: Efficient state handling for reliable performance.
- **Cross-Platform**: Deployable uniformly on both Android and iOS devices.

### 🚀 Local Setup (Manual)
If you prefer running the mobile app manually instead of using Docker:
1. Ensure **Flutter SDK** and an emulator/physical device are ready.
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app:
   ```bash
   flutter run
   ```

*(For automated Docker setup, please refer to the root `README.md`)*

## 🇸🇦 القراءة باللغة العربية (Arabic Documentation)

مرحباً بك في الواجهة الأمامية (تطبيق الهاتف المحمول) والخاصة بمنصة **My Party**. تم تصميم وبناء هذا التطبيق بعناية فائقة باستخدام **Flutter** ليعمل بشكل سريع وسلس على أجهزة أندرويد و iOS والتكامل المباشر مع واجهات تطبيقات (REST APIs) الخاصة بنا و Socket.io لتحصل على إشعارات الفعاليات بشكل لحظي.

### ✨ الميزات الرئيسية
- **واجهة عصرية وحديثة**: تجربة مستخدم سلسة وأنيقة مبنية بالكامل باستخدام مكونات Flutter المتقدمة.
- **بيانات للحظية (Real-Time)**: مزامنة فورية للإشعارات والفعاليات باستخدام تقنية Socket.io.
- **إدارة الحالة بكفاءة**: معالجة سلسة للبيانات لضمان عدم حدوث أي تأخير (Lag).
- **التشغيل عبر المنصات**: كود موحد يعمل بسلاسة على منصتي Android و iOS.
